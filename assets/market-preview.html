W​SL

DSH × WSL

在 Windows 上执行 Linux 命令、互转路径、体检 WSL 环境
无需选择模式
左侧栏开关面板
可选：WSL 终端
功能
  • wsl 执行 Linux 命令

    每次调用一个全新 shell，在 WSL 里跑命令并回传结果。

  • wsl-path 路径互转

    Windows 路径 ↔ /mnt/...、\\wsl.localhost\。

  • wsl-env 环境体检

    发行版、内核、systemd、cgroup、docker、GPU、挂载盘。

  • stdin 输入

    把内容喂给命令，不再只能拼到命令行里。

  • 退出码 · 信号 · 超时

    三种结束方式各自如实标记，超时不会静默挂住。

  • 输出截断落盘

    超出流上限时截断，并把完整输出写进文件、给出路径。

  • 后台作业

    runInBackground 转成后台任务，用 job_output / job_kill 读回或中止。

  • 危险命令守卫

    删除、分区、关机等必须显式放行 allowDangerous。

  • 自动路径转换

    命令里的 Windows 路径自动转成 /mnt/...。

  • 工作目录策略

    默认跟随会话工作区，也可固定一个 Linux 目录。

  • 左侧栏开关面板

    每个能力一个开关，批量操作只有一处「全部恢复默认」。

  • 可选：WSL 终端

    把侧边栏「新建终端」指向 WSL（真 PTY），默认不开。

边界（如实说明）
WSL 调用发生在 DSH 沙箱层之下，文件策略约束不到它；项目放在 Windows 盘时仍是 Windows 文件系统语义（9p：慢、无 inotify、权限位不生效）。
