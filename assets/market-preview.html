DSH × WSL

在 Windows 上执行 Linux 命令 —— 命令执行层基本对齐原生 Linux DSH
左侧栏开关面板
可选：侧边栏 WSL 终端
零依赖
三个工具
wsl 命令执行

每次调用一个全新 shell；可喂 stdin、可设超时；退出码 / 信号 / 截断都如实回传。

wsl-path 路径互转

Windows 路径 ↔ /mnt/...、\\wsl.localhost\ 双向转换。

wsl-env 能力体检

发行版、内核、systemd、cgroup、GPU 直通、docker、挂载盘与两侧配置一次看清。

长任务后台跑

runInBackground 交给内置 job 工具读回 / 中止，前台超时不再拖死。

安全与可观测

危险命令守卫（删除 / 分区 / 关机需显式放行）；输出按流上限截断，超限会自动落盘完整文件并提供路径。

如实说明的限制
两条边界

① WSL 调用发生在 DSH 沙箱层之下，文件策略约束不到它；② 项目放在 Windows 盘时仍是 Windows 文件系统语义（9p：慢、无 inotify、权限位不生效）。

一次真实调用
wsl · wsl "cd /mnt/d/proj && npm test"

返回 stdout / stderr / exitCode，并标记信号、超时与截断；长任务加 runInBackground: true 拿 jobId，用 job_output / job_kill 读回或中止。可选一条 patch 还能把桌面版「新建终端」指向 WSL（真 PTY，默认不开）。
